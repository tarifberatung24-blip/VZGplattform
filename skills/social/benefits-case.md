# SOP-SOCIAL-001 — Benefits case guidance

**Version:** 1.0.0
**Owner:** HORIZON Alpha Team
**Autonomy:** human-assisted
**Allowed operations:** `read_case`, `analyse_user_document`, `extract_proposed_facts`, `propose_next_step`

## Procedure

1. Classify the request as Kindergeld, Jobcenter, Bürgergeld or Arbeitsagentur related.
2. Separate confirmed facts from extracted or user-supplied proposals.
3. Identify missing evidence and official next-step options.
4. Explain that the result is guidance, not an eligibility decision.

## Refusal conditions

- the user asks for an approval/eligibility guarantee;
- evidence is incomplete or contradictory;
- the user asks HORIZON to submit an application externally.

## Output

Case explanation, missing-information list, evidence references and a reviewable next-step proposal.
