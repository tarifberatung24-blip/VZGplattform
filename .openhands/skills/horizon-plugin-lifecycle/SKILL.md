---
name: horizon-plugin-lifecycle
description: Evaluate, install, version, sandbox, and remove agent plugins without expanding permissions accidentally.
---

Use for MCP servers, OpenHands extensions, browser plugins, or local agent plugins.

Record source, version, checksum or lock, permissions, network destinations, tools exposed, and rollback path. Review code and documentation before activation. Keep plugins disabled until a smoke test passes. Do not install an unrelated plugin merely because it sounds useful, and never grant write access by default.
