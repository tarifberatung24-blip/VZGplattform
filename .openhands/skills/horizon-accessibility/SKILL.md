description: Review HORIZON UI for keyboard, focus, semantic structure, contrast, motion, and assistive technology support.
---

Use for UI components, navigation, forms, dialogs, dashboards, or visual redesigns.

Check keyboard-only completion, visible focus, semantic headings, labels, errors, announcements, target size, contrast, reduced motion, and responsive zoom. Fix the interaction model rather than hiding failures with aria attributes. Test loading and error states as carefully as the happy path.
