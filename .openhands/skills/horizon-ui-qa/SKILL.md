---
name: horizon-ui-qa
description: Verify HORIZON routes and responsive UI with browser inspection, accessibility checks, and visual smoke tests.
---

Use for homepage, dashboard, onboarding, forms, navigation, responsive layouts, or visual regressions.

Test the real route at desktop and mobile widths. Verify loading, empty, error, keyboard focus, visible labels, dialogs, and recovery after reload.
For 3D or animated surfaces, verify reduced-motion behavior, usable fallback content, contrast, and performance on a low-power viewport.
Capture screenshots only for review; do not treat a screenshot as proof of backend correctness. Report browser-only findings separately from API or persistence findings.
